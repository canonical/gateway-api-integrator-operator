# Tutorial

The tutorial in this documentation set walks you through a basic deployment of the Gateway API integrator charm using the `ingress` relation endpoint. 

The charm can also use the `gateway-route` endpoint to provide traffic routing for an application, which gives you more control over the ingress configuration and the ability to integrate with multiple ingress-requiring backends. See {ref}`ingress-configurator-charm:tutorial_getting_started` to walk through a basic deployment with the `ingress-configurator` charm.
